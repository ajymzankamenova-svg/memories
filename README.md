# Сферы памяти

Статический сайт без Node.js, npm, Next.js и шага сборки.

## Запуск

Для входа с хешированием паролей откройте сайт через HTTPS или localhost. Из корня проекта запустите `python -m http.server 8000`, затем перейдите на `http://localhost:8000`.

## Публикация

GitHub Pages: загрузите файлы в корень репозитория и включите Pages.

Vercel: импортируйте репозиторий; сборка не нужна, каталог публикации — `.`.

Аккаунты (с паролями в виде PBKDF2-хешей), письма и записи хранятся в localStorage этого браузера. Это клиентский режим для прототипа, а не серверная защита данных. Чтобы входить в один аккаунт с разных устройств и обеспечить настоящую приватность, подключите серверную базу и авторизацию. Отправка другу также работает локально.
